## 📖 Project Overview

Student Day Planner is a productivity tool built to help students effectively manage their academic responsibilities. The application provides an organized workspace where users can plan their day, keep track of tasks, and maintain consistency in their studies.

Whether you're preparing for exams, managing assignments, or building study habits, this planner helps you stay on track.

---

## ⚙️ How It Works

1. Add your daily tasks and goals.
2. Organize tasks according to priority.
3. Track completed activities.
4. Monitor your daily productivity.
5. Stay focused on your academic objectives.

## ▶️ Installation

```bash

```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
